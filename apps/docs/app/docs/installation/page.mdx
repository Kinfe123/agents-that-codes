# Installation

This page explains how to get Coding Agent Template into a runnable state. It separates the setup model from command lists so readers understand what each step is preparing.
## Setup Model
Installation has three jobs: install the package dependencies, provide the runtime configuration the project documents, and verify the command that exercises the main workflow.
## What Gets Configured
- Dependencies provide the framework, CLI, adapters, and runtime libraries used by the project.
- Environment variables provide documented secrets, URLs, provider tokens, and deployment-specific behavior.
- Scripts provide repeatable entrypoints for local development, production builds, tests, and release tasks.
## Successful Setup Looks Like
- Dependencies install with the package manager already used by the project.
- Required environment variables are present before runtime commands are executed.
- The primary command starts, builds, or verifies the project without needing undocumented manual steps.
## Install Dependencies
Run `pnpm install` from the project root.
## Configure Environment Variables
Copy `.env.example` into `.env` and fill in the required values before running the project.
- `AI_GATEWAY_API_KEY` - API key used to authenticate with the named provider.
- `ANTHROPIC_API_KEY` - Required API Keys
- `CURSOR_API_KEY` - Optional API Keys (depending on which agents you want to use)
- `ENCRYPTION_KEY` - Optional Encryption Key (used to encrypt MCP secrets in the database)
- `GITHUB_TOKEN` - Token used to authenticate a runtime, bot, webhook, or provider integration.
- `NPM_TOKEN` - Token used to authenticate a runtime, bot, webhook, or provider integration.
- `OPENAI_API_KEY` - OpenAI API key used when the project generates AI answers from retrieved context.
- `POSTGRES_URL` - Database
- `VERCEL_PROJECT_ID` - defaults to `your-project-id` when not provided.
- `VERCEL_TEAM_ID` - Vercel Sandbox Configuration
- `VERCEL_TOKEN` - Token used to authenticate a runtime, bot, webhook, or provider integration.
## Verify the Build or Runtime Command
The most relevant command detected right now is `pnpm start`.

## Useful Commands
- `dev` runs `next dev --turbopack` and starts the local development workflow.
- `build` runs `next build --turbopack` and creates the production build or compiled package artifacts.
- `start` runs `next start` and starts the runtime entrypoint after dependencies or build output are ready.
