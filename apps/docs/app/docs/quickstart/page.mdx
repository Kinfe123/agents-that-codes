# Quickstart

Use this quickstart to move from a fresh checkout to a configured local run of Coding Agent Template.

## Prerequisites
This project uses `pnpm` as its package manager.
Environment-backed behavior is present, so configuration is part of the first-run path.

## Run locally
1. Install dependencies with `pnpm install`.
2. Copy `.env.example` to `.env` and set the required values.
3. Run `pnpm dev` to start or verify the project locally.

## Repository scripts
These commands are useful after the first run because they cover the main local development, build, and verification tasks.

- `dev`: `next dev --turbopack` starts the local development servers or watchers.
- `build`: `next build --turbopack` creates the production build or compiled package artifacts.
- `start`: `next start` starts the runtime process after dependencies or build output are ready.
