# Environment Variables

Coding Agent Template needs runtime values before commands, integrations, or deployed surfaces can start safely.

## Runtime contract
Keep these values outside source control, mirror the names from `.env.example` when present, and load them before starting local or production runtime.

## Required environment variables
- `VERCEL_PROJECT_ID` - defaults to `your-project-id` when not provided.
- `ENCRYPTION_KEY` - Optional Encryption Key (used to encrypt MCP secrets in the database)
- `CURSOR_API_KEY` - Optional API Keys (depending on which agents you want to use)
- `VERCEL_TEAM_ID` - Vercel Sandbox Configuration
- `ANTHROPIC_API_KEY` - Required API Keys
- `GITHUB_TOKEN` - Token used to authenticate a runtime, webhook, or provider integration.
- `OPENAI_API_KEY` - OpenAI API key used when the project generates AI answers from retrieved context.
- `POSTGRES_URL` - Database
- `VERCEL_TOKEN` - Token used to authenticate a runtime, webhook, or provider integration.
- `AI_GATEWAY_API_KEY` - API key used to authenticate with the named provider.

## Verify changes
- Run `pnpm dev` after setting the variables.
- Open the app, route, or command that reads this configuration and confirm it reaches the expected state.
- If setup fails, check missing variables, database connectivity, and adapter-specific settings before debugging application logic.
